## ✨ Features
- ✅ Smart task prioritization by deadline & effort
- ✅ Analytics dashboard with completion ring
- ✅ Priority levels — Critical, High, Medium, Low
- ✅ Category filtering — Work, Health, Learning, Finance
- ✅ Real-time search and filtering
- ✅ Task completion tracking
- ✅ Dark theme professional UI
- ✅ Fully responsive design

## 🚀 Run Locally
```bash
git clone https://github.com/kavigamage-da/taskflow-ai
cd taskflow-ai
npm install
npm run dev
```

---

## 📁 Project Structure
```
src/
├── components/
│   ├── analytics/    # Charts and stats
│   ├── animations/   # Animated elements
│   ├── layout/       # Sidebar and layout
│   ├── task/         # Task cards and filters
│   └── ui/           # Reusable UI components
├── store/            # State management
└── App.tsx           # Main application
```

---

## 📊 System Design
```
User Interface (React + TypeScript)
        ↓
State Management (Zustand)
        ↓
Component Layer (Shadcn/UI + Tailwind)
        ↓
Local Storage (Persistence)
```
