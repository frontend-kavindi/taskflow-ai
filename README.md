# 🤖 TaskFlow AI — Smart Task Manager

> AI-powered task manager with smart prioritization built 
> with React, TypeScript and Tailwind CSS.

## 🌐 Live Demo
👉 **[View Live App](https://kavindi-taskmanager.netlify.app)**

## ✨ Features
- ✅ Smart task prioritization by deadline & effort
- ✅ Analytics dashboard with completion ring
- ✅ Priority levels — Critical, High, Medium, Low
- ✅ Category filtering — Work, Health, Learning, Finance
- ✅ Real-time search
- ✅ Dark theme UI

## 🛠️ Tech Stack
- React 18 + TypeScript
- Tailwind CSS
- Vite
- Shadcn/UI Components

## 🚀 Run Locally
```bash
npm install
npm run dev
```
